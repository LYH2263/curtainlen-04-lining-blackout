# 19-curtainlen（窗帘用布）

Curtainlen — 成品宽×褶倍率 + 上下边折；换算布长米数

## 启动

```bash
docker compose up --build
```

| 入口 | 地址 |
| --- | --- |
| 前端 | http://localhost:4800 |
| API | http://localhost:9800 |

## 主链

窗宽层高+褶量 → 布长 → 窗户示意

## 遮光里衬

算料台可开关遮光里衬：里衬幅数同主帘，裁剪高 = 层高 + 里衬上下折边，里衬米数与主帘分列。默认里衬折边在设置页维护；保存的算料记录同时写入主帘米、里衬米、折边与开关，历史记录只展示保存那一版，改默认折边不重算旧单。里衬折边为负时整单失败、不入历史。

## 技术栈

Python 3.12 + FastAPI + SQLite；Vue 3 + Vite + Nginx。
